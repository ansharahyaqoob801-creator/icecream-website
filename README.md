## ✦ ABOUT THE PROJECT

The **Purple Icecream 3D Website** is a creative front-end project designed to showcase ice cream products through an elegant interface, a coordinated purple color palette, animated visual elements, and responsive layouts.

The goal is to create a delightful browsing experience while demonstrating practical knowledge of modern web design and development.

## ✦ GETTING STARTED

Run the project locally in just a few steps.

**1. Clone the Repository**

```bash
git clone https://github.com/YOUR-USERNAME/PurpleIcecream3D.git
```

**2. Open the Project Folder**

```bash
cd PurpleIcecream3D
```

**3. Launch the Website**

Open the folder in **Visual Studio Code** and launch `index.html` using the Live Server extension, or open the HTML file directly in your browser.

---

## ✦ DEPLOYMENT WITH GITHUB PAGES

Publish the project online using GitHub Pages.

1. Upload the project files to your GitHub repository.
2. Open your repository's **Settings**.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Click **Save** and wait for deployment to complete.

**Your website URL will follow this format:**

`https://YOUR-USERNAME.github.io/PurpleIcecream3D/`
